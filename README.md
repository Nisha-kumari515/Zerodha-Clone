# Zerodha Clone

A full-stack trading platform clone built to practice modern web development,
frontend-backend integration, and database-driven application development.

## About the Project

This project recreates selected features and workflows of an online trading
platform. It uses a React frontend and a Node.js/Express backend to demonstrate
full-stack application development.

## Features

- React-based user interface
- Frontend and backend integration
- REST API communication
- MongoDB database integration
- Organized frontend, backend, and dashboard components
- Frontend deployment using AWS Amplify
